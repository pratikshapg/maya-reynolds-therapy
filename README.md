# Dr. Maya Reynolds, PsyD — Therapy Website

A responsive therapist website concept designed for Dr. Maya Reynolds, PsyD, a fictional licensed clinical psychologist profile based in Santa Monica, California.

## Overview

This project recreates the structure of a reference therapist website while introducing a fresh visual identity, updated content, and a cohesive photography direction.

## Features

* Responsive homepage for desktop, tablet, and mobile
* Sage-green, warm-sand, terracotta, and cream color palette
* Therapist introduction and biography
* Anxiety and Panic Therapy
* Trauma Therapy and EMDR
* Burnout and Perfectionism Counseling
* Our Office section
* Frequently asked questions
* Location-focused page metadata and SEO
* Accessible, user-friendly navigation and calls to action

## Tech Stack

* Next.js
* React
* Tailwind CSS
* TypeScript or JavaScript, depending on the project configuration

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd maya-reynolds-therapy
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

### Production Build

```bash
npm run build
```

## Project Structure

* `app/` — Application pages, layout, and global styles
* `components/` — Reusable website sections and UI components
* `lib/` — Website content and image configuration
* `public/images/` — Website images and visual assets

Actual folder names may vary slightly depending on the final project structure.

## Design Direction

The visual identity combines deep sage green, warm sand, muted terracotta, and cream to create a calm, welcoming, and professional experience.
